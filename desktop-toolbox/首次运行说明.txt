桌面工具箱 — 首次运行说明（2026-11-28-11）
====================================

1. 把「桌面工具箱-2026.11.28-11.zip」解压到任意文件夹
   （比如 D:\桌面工具箱），双击里面的「DesktopToolbox.exe」
   就能用，不用安装。数据存在 exe 旁边的 data 目录里，
   换电脑时整个文件夹拷走，数据都在。Windows 弹
   SmartScreen 时，点「更多信息」→「仍要运行」。
   VLC 不在安装包里，在工具管理的推荐软件里安装，
   或第一次用播放器时点后备下载；浏览器是内嵌的，
   不用下载 Chromium，打开就能用。

2. 第一次打开，先看到左侧菜单边栏（功能图标网格、
   最近聊天、底部的设置齿轮与「新对话」按钮），
   右侧是主内容区；窗口无边框，右上角有悬浮的
   最小化、最大化、关闭按钮，侧边栏顶部可拖动窗口。
   点 × 默认只把窗口收到托盘，程序继续跑；想彻底退出
   点托盘菜单里的「退出」。菜单点哪项都是工具箱
   自己的功能、数据只存在本机。最近栏里只显示
   智能体的聊天历史。菜单窗口可以分离成独立悬浮窗
   （点边栏底部的分离按钮），合回主窗口点菜单窗口里
   的「合并回主窗口」。
   - 工具管理：发现软件、已安装、可更新、工具来源。
     可更新里分软件包、已安装仓库工具、环境与依赖三个子页签；
     GitHub 登录在「工具来源」页；必备环境和安装前确认依赖
     在最后一页。推荐软件里有按分类整理的常用软件，
     VLC 也在里面。
   - 播放器：点已安装的播放器打开内嵌播放界面，
     本地文件与直链直接在工具箱里播；也可以点「外部 VLC
     打开」用 VLC 窗口播。PotPlayer、mpv 没装
     时显示未安装，去工具管理搜了装上就能用。
     右上角下拉可以设默认播放器。
   - 浏览器：点「打开内嵌浏览器」直接打开内嵌浏览器，
     网页直接在工具箱里打开，不用安装；已安装的
     Chrome、Edge 也可从这里打开。右上角下拉可以设
     默认浏览器。
   - 设置：分常规、更新、窗口与系统、备份与同步、插件、
     自检与安装、手机远程七个分组，含下载默认存放位置、
     组件目录、窗口透明、关闭到托盘、开机自启。
   - 智能体：先在智能体页添加一个（选服务商、填 API 密钥
     与模型，或选网页端粘贴网页令牌），再点「新对话」开始聊；
     密钥与对话只存本机。聊天窗口就是自然语言入口：直接说
     「帮我装个 VLC」「跑一下这段代码」「打开 Chrome」
     「查一下系统状态」，智能体调本机工具真实执行；删文件、
     卸载、升级、装驱动这类操作执行前会先问你确认，点
     「确认执行」才跑。没填密钥时大模型回复不可用，但装软件、
     跑代码这类本地指令不用密钥也能用。
   - 视频下载：在内嵌浏览器里打开视频页会自动抓到视频，
     点右下角悬浮图标进视频下载页下载；也可以粘贴视频页
     地址，嗅探列出资源与清晰度，点下载即可；m3u8、国内站
     与通用站自动选对应的下载引擎。页面里的种子文件与磁力
     链接会出现在嗅探框的「种子/磁力」页签：种子文件点下载
     保存，磁力链接可复制或交给本机 BT 客户端打开（工具箱
     本身不下 BT 内容）。登录后跳转不会清掉刚抓到的内容，
     换到别的网站时才清并存一份历史快照。
   - 注册：数据只存在本机；注册的邮箱可用 Mail.tm
     自动收码（提取号码建临时邮箱，自动刷新每 10 秒拉取）；
     短信没有公开接口，手动添加。
   - 代理：在代理页填手动 HTTP 代理并测试，用于智能体、
     创作、代码、图像与 GitHub 请求。Tun 模式需先在代理页
     检测/安装 WinTun 驱动（驱动文件已随安装包内置，不再下载；
     首次安装弹一次系统确认框拉起提权 helper，日常开关不再提权），再
     点「启动 Tun」。智能/全局模式不需要 Tun 与管理员权限。Pioneer 在代理页登录自己的账号后连接，
     账号密码与节点凭据只存本机；点地区名称连接，再点同一名称
     断开，点别的名称切换地区。
   - 代码：用本机解释器真实运行（Python、Node 等），没装
     解释器时先在设置「自检与安装」里一键安装。
   - 远程（手机）：设置 → 手机远程里扫码配对后，手机浏览器
     打开工具箱远程页面，可看状态、发聊天、开软件；同一
     Wi-Fi 直连，出门走 Tailscale；危险操作默认关闭，
     需另开并在手机上二次确认。
   - 自检与安装：设置页里检测 Python、Node、Git、winget、
     PowerShell 与 WinTun 驱动是否齐全，缺的给一键安装；装 WinTun 驱动
     时首次弹一次系统确认框拉起提权 helper，装好后日常使用不再提权。
     VLC 与 Chromium 不在自检里（VLC 在推荐软件里按需装，
     浏览器是内嵌的，不用装）。
   - 工具来源：工具管理 → 工具来源除了四个内置来源，
     还能加自定义来源（winget 源、GitHub 仓库、网址），
     也能从本机已装程序导入（扫描注册表，加进清单，带
     安装指导）。
   - 插件：设置页「插件」一节可从本机文件夹或 GitHub
     地址安装插件，启用/禁用/删除；插件入口出现在左
     侧菜单里。插件只能调工具箱给它的接口，碰不到密钥文件。
   - 备份与同步：设置页「备份与同步」一节可一键导出/
     导入全部本地数据成一个备份文件（默认不含密钥，可
     选密码保护）；同步文件夹是手动同步：指定文件夹后
     点「同步到文件夹」写一份备份进去，另一台电脑从同
     一文件夹选备份恢复，同步前会自动备份当前数据。
     诊断日志也在这一节：主进程异常会记到本机日志里，
     可一键导出诊断包（只含版本、自测结果与脱敏日志，
     不含任何密钥，不上传）。
   - 屏幕翻译：按 Ctrl+Alt+T，框选屏幕上的一块区域，
     智能体认字并翻译，结果显示在悬浮窗里。

3. 第一次打开工具管理，先点「可更新 → 环境与依赖」里
   的「检查必备」，缺什么点「一键安装」装上
   （winget、.NET、VC++、Python、Node）。装软件时工具箱
   会先查依赖、列出来让你确认再一起装；有冲突会先提示
   原因和处理办法，不要静默装。清单 / 说明里没写的依赖，
   工具箱会如实说查不到。

4. 日常使用：
   - 「工具管理」：搜软件（含微软商店未安装的）、装/卸/
     真的更新、把整机软件导成清单，换电脑导入装回。
     更新完会自动刷新已安装并显示更新前后的版本号。
     发现软件只搜「工具来源」里启用的来源。
   - 「工具管理 → 工具来源 → GitHub 登录」：先粘贴个人访问令牌
     点「登录」（令牌只存在本机，不会写进代码），再去「发现软件」
     搜仓库、看 Releases，有 exe / msi 安装包的直接点安装，装完后
     在「已安装」里刷新核对；「可更新 → 已安装仓库工具」会检测
     这些仓库工具有没有新版本。
   - 一键上传已删掉，不用找了（各主机上限太低）。

5. 组件来源与更新：
   VLC 与 Chromium 都不在安装包里；VLC 在工具管理的
   推荐软件里安装，浏览器是内嵌的，不用下载 Chromium。
   许可证原文在安装包的 bundled/licenses/ 里。
   工具箱自己更新：代码热更新，只手动、不自动。打开工具
   箱「设置 → 更新」，点「检查更新」，工具箱去 GitHub 仓库
   拉更新清单，只下载有变化的代码文件（约 500KB），逐个
   校验后替换，点「重启生效」后用新版本；下载前会先备份旧
   文件，下载或校验失败就保留旧文件，不会把程序弄坏。
   Electron 这些大块头不走热更新，只有它们
   变了才需要重新下载整个文件夹。
   注意：更新清单已随代码推上 GitHub 仓库，查不到时
   会如实显示「未找到更新信息」。

6. 工具箱打不开或闪退：设置 → 备份与同步 → 诊断日志
   里有最近的错误记录；也可以直接看 exe 旁边
   data\logs\ 里按天记的日志（只留最近 7 天）。
   下次启动时工具箱会提示上次崩溃并给出恢复选项。

7. 卸载：直接删整个文件夹即可；配置与内置组件都在 exe
   旁边的 data 目录里（旧版便携版的数据在
   %APPDATA%\muse-desktop-toolbox，第一次启动新版时会自动
   拷到 data 目录，旧目录留着当备份）。
   注意：令牌存在 data\config.json 里，
   清配置时令牌也会一起清掉。
