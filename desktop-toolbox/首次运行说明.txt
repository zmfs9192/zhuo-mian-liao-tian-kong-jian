桌面工具箱 — 首次运行说明（2026-11-27-2）
====================================

1. 把「桌面工具箱-2026.11.27-2.zip」解压到任意文件夹
   （比如 D:\桌面工具箱），双击里面的「桌面工具箱.exe」
   就能用，不用安装。数据存在 exe 旁边的 data 目录里，
   换电脑时整个文件夹拷走，数据都在。Windows 弹
   SmartScreen 时，点「更多信息」→「仍要运行」。
   包约 204MB：VLC 已打包在里面，第一次打开启动时自动
   解压好；Chromium 不在安装包里，第一次用浏览器时再下载
   （约 209MB，带进度、可续传，下完自动配置好再打开）。
   没下载前点浏览器会明确提示去下载，不会假装能打开。

2. 第一次打开，先看到桌面聊天空间式布局：
   左侧是菜单边栏（功能图标网格、
   最近聊天、底部的设置齿轮与「新对话」按钮），
   右侧是主内容区；窗口无边框，右上角有悬浮的
   最小化、最大化、关闭按钮，侧边栏顶部可拖动窗口。
   左侧是「工具箱菜单」，「工具箱」是选中态，右侧默认
   就是工具箱内容。菜单共 15 项，点哪项都是工具箱
   自己的功能、数据只存在本机（与空间不互通）；「空间」
   不在菜单里，右下角有个绿色小圆点，点它才会打开空间，
   在空间页再点一次切回工具箱。第一次点会提示填空间地址：
   在空间里打开小助手页，复制空间地址粘贴进来保存一次
   即可。点「‹ 工具箱」返回工具箱总览。最近栏里只显示
   智能体的聊天历史。
   - 工具管理：发现软件、已安装、可更新、工具来源。
     可更新里分软件包、已安装仓库工具、环境与依赖三个子页签；
     GitHub 登录在「工具来源」页；必备环境和安装前确认依赖
     在最后一页。
   - 播放器：先是应用列表，点 VLC 打开内嵌播放界面，
     本地文件与直链直接在工具箱里播；也可以点「外部 VLC
     打开」用 VLC 窗口播。PotPlayer、mpv 没装
     时显示未安装，去工具管理搜了装上就能用。
     右上角下拉可以设默认播放器，空间调用按默认的走。
   - 浏览器：先是应用列表，点 Chromium 打开内嵌浏览器
     界面，网页直接在工具箱里打开；也可以点「在外部
     Chromium 窗口中打开」。右上角下拉可以设默认浏览器。
     第一次点 Chromium 时还没下载，会提示先下载（约 209MB），
     下完才能打开；设置页「自检与安装」里也能看到 Chromium
     「未下载」并点下载按钮。
   - 设置：分常规、更新、窗口与系统、空间与调用、备份与
     同步、插件、自检与安装多个分组，含下载默认存放位置、
     组件目录、空间地址、空间调用开关。
   - 智能体：先在智能体页添加一个（选服务商、填 API 密钥
     与模型，或选网页端粘贴网页令牌），再点「新对话」开始聊；
     密钥与对话只存本机。聊天窗口就是自然语言入口：直接说
     「帮我装个 VLC」「跑一下这段代码」「打开 Chrome」
     「查一下系统状态」，智能体调本机工具真实执行；删文件、
     卸载、升级、装驱动这类操作执行前会先问你确认，点
     「确认执行」才跑。没填密钥时大模型回复不可用，但装软件、
     跑代码这类本地指令不用密钥也能用。
   - 视频下载：在内嵌浏览器里打开视频页会自动抓到视频，
     点右下角悬浮图标进视频下载页下载；也可以粘贴视频页
     地址，嗅探列出资源与清晰度，点下载即可；m3u8、国内站
     与通用站自动选对应的下载引擎。
   - 注册：数据只存在本机；注册的邮箱可用 Mail.tm
     自动收码，短信记录仍需手动添加。
   - 代理：在代理页填手动 HTTP 代理并测试，用于智能体、
     创作、代码、图像与 GitHub 请求。Tun 模式需先在代理页
     检测/安装 WinTun 驱动（官网下载，需管理员权限），再
     点「启动 Tun」。Pioneer 在代理页登录自己的账号后连接，
     账号密码与节点凭据只存本机。
   - 代码：用本机解释器真实运行（Python、Node 等），没装
     解释器时先在设置「自检与安装」里一键安装。
   - 注册：邮箱可用 Mail.tm 自动收码（提取号码建临时邮箱，
     自动刷新每 10 秒拉取）；短信没有公开接口，手动添加。
   - 远程：启动远程画面后，同一局域网的浏览器输入配对码
     可看电脑画面（只能看，不能操作）。
   - 自检与安装：设置页里检测 Python、Node、winget、WinTun
     驱动、VLC、Chromium 是否齐全，缺的给一键安装；装驱动
     需管理员权限，安装前会明确提示。Chromium 没下载时
     这里显示「未下载」，点下载按钮即可。
   - 工具来源：工具管理 → 工具来源除了四个内置来源，
     还能加自定义来源（winget 源、GitHub 仓库、网址），
     也能从本机已装程序导入（扫描注册表，加进清单，带
     安装指导）。
   - 插件：设置页「插件」一节可从本机文件夹或 GitHub
     地址安装插件，启用/禁用/删除；插件入口出现在左
     侧菜单里。插件只能调工具箱给它的接口，碰不到密钥文件。
   - 备份与同步：设置页「备份与同步」一节可一键导出/
     导入全部本地数据成一个备份文件（默认不含密钥，可
     选密码保护）；同步文件夹是手动同步：指定文件夹后
     点「同步到文件夹」写一份备份进去，另一台电脑从同
     一文件夹选备份恢复，同步前会自动备份当前数据。
   - 悬浮圆点：右下角绿色小圆点按住可拖动，轻点切换空间。
     空间调用的说明是：空间使用工具箱默认的浏览器/播放器。

3. 第一次打开工具管理，先点「可更新 → 环境与依赖」里
   的「检查必备」，缺什么点「一键安装」装上
   （winget、.NET、VC++、Python、Node）。装软件时工具箱
   会先查依赖、列出来让你确认再一起装；有冲突会先提示
   原因和处理办法，不要静默装。清单 / 说明里没写的依赖，
   工具箱会如实说查不到。

4. 日常使用：
   - 「工具管理」：搜软件（含微软商店未安装的）、装/卸/
     真的更新、把整机软件导成清单，换电脑导入装回。
     更新完会自动刷新已安装并显示更新前后的版本号。
     发现软件只搜「工具来源」里启用的来源。
   - 「工具管理 → 工具来源 → GitHub 登录」：先粘贴个人访问令牌
     点「登录」（令牌只存在本机，不会写进代码），再去「发现软件」
     搜仓库、看 Releases，有 exe / msi 安装包的直接点安装，装完后
     在「已安装」里刷新核对；「可更新 → 已安装仓库工具」会检测
     这些仓库工具有没有新版本。
   - 一键上传已删掉，不用找了（各主机上限太低）。

5. 组件来源与更新：
   VLC 3.0.21（VideoLAN 官方，GPLv2）已打包在安装包里；
   Chromium 快照 160.0.8184.0（Chromium 官方快照服务，BSD
   许可证；不是 Google Chrome 稳定版）不再打包，首次使用
   浏览器时再从官方快照地址下载。许可证原文在安装包的
   bundled/licenses/ 里。组件不单独更新，只随工具箱版本
   一起更新。
   工具箱自己更新：代码热更新，只手动、不自动。打开工具
   箱「设置 → 更新」，点「检查更新」，工具箱去 GitHub 仓库
   拉更新清单，只下载有变化的代码文件（约 500KB），逐个
   校验后替换，点「重启生效」后用新版本；下载前会先备份旧
   文件，下载或校验失败就保留旧文件，不会把程序弄坏。
   Electron、VLC、Chromium 这些大块头不走热更新，只有它们
   变了才需要重新下载整个文件夹。
   注意：更新清单文件目前还没有推上 GitHub 仓库，查不到时
   会如实显示「未找到更新信息」；需先把代码与清单一起推上
   GitHub，才能真正更新到。

6. 如果空间里点「用工具箱打开」没反应：
   多半是协议没注册上。打开工具箱「设置 → 空间调用（电脑端）」，
   看协议状态一行，点「重新注册」；还不行就重装一次工具箱。
   另外确认那里的开关是打开的。

7. 卸载：直接删整个文件夹即可；配置与内置组件都在 exe
   旁边的 data 目录里（旧版便携版的数据在
   %APPDATA%\muse-desktop-toolbox，第一次启动新版时会自动
   拷到 data 目录，旧目录留着当备份）。
   注意：令牌存在 data\config.json 里，
   清配置时令牌也会一起清掉。
