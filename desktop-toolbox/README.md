## 工具管理：四点怎么做到

1. **搜索未安装的商店应用**：「发现软件」搜关键词时，winget 默认源和微软商店源（msstore）各搜一次、按 ID 去重，未装的结果直接点「安装」。
2. **真的更新**：「可更新」页点「更新」或「全部更新」跑 `winget upgrade` / `upgrade --all`；点单个更新时记下旧版本，完成后自动刷新已安装清单并核对，提示「旧版本 → 新版本，已在已安装里核对」；已安装里找不到时如实提示再刷新一次。
3. **GitHub 登录并搜索仓库**：工具管理 → 可更新 → GitHub 页，先粘贴个人访问令牌（Personal Access Token）点「登录」。令牌只存在本机 `config.json` 里，不写进代码、不上传；登录后搜仓库（按星数排）、看 Releases；Release 里有 exe / msi 安装包的点「安装」下载并启动安装程序，装完后工具箱会在 8 秒后刷新一次已安装清单核对（按仓库名找）。
   - 建令牌：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)，搜公开仓库不勾权限也能用；要装私有仓库的 Release 再按需加权限。
4. **安装后在已安装中显示**：winget 安装 / 更新任务完成时自动刷新已安装清单；GitHub 安装包启动后，工具箱 8 秒后刷新一次核对并提示。个别 exe 安装包不在 winget 清单里时，提示会如实说没找到、请再刷新一次。

## 必备环境与依赖（v1.2.0）

- **必备环境**：工具管理 → 可更新 → 环境与依赖（最后一页）有「必备环境」卡片，点「检查必备环境」会查 winget、.NET 桌面运行库 8、VC++ 2015-2022 运行库 x64、Python 3、Node.js LTS；缺的点「一键装齐缺的」用 winget 装。winget 本身缺了装不了（没有 winget 就没法用 winget 装东西），会明确提示去微软商店装「应用安装程序」。
- **装软件前查依赖**：点「安装」时先查依赖再确认。winget 包查清单里的 Dependencies；GitHub 安装包查 Release 说明里提到的依赖（.NET / VC++ / Python / Node）。缺依赖先列出来，点「依赖和本体一起装」会先装依赖再装本体；点「只装本体」会跳过依赖；点「取消」不装。
- **装完核对依赖**：装完自动刷新已安装清单，本体和依赖都要在里面核对到；GitHub 安装包是外部安装向导，工具箱 8 秒后刷新一次核对并提示。
- **依赖冲突**：已装版本低于要求版本时，安装前明确提示冲突原因和处理办法（升级依赖 / 并存 / 跳过）。VC++ 各版本累计、.NET 大版本可并存，一般不冲突，界面上会写明。
- **如实说明的边界**：winget 清单经常不声明依赖，Release 说明是自由文本——没声明 / 没写清楚的依赖，工具箱会说「无法自动检测」，不假装已检测；要求版本没写明的，只能报「未知，按本体要求为准」。

## 空间怎么调用它（设置 → 空间调用（电脑端））

安装时注册自定义协议 **muse-toolbox://**（打包版由安装器注册，程序每次启动再兜底注册一次当前用户级关联）：

- `muse-toolbox://play?url=<视频地址>` → 用默认播放器播放（空间「媒体 → 影视」切到 VLC 时的主按钮）
- `muse-toolbox://browse?url=<网页地址>` → 用默认浏览器打开（空间使用工具箱默认的浏览器/播放器）
- `muse-toolbox://home` → 打开工具箱主窗口

设置里「空间调用（电脑端）」一节有开关：默认打开；关掉后协议调用会被拒绝，空间走它自己的兜底（vlc:// / 复制地址）。协议状态和「重新注册」按钮也在这一节里。

工具箱没运行时，协议唤起会先把它启动再处理；已运行时转发给已有窗口（单实例）。空间是网页、没法直接启动本地程序，协议是唯一正路；工具箱没装时，空间侧保留 vlc:// 唤起与复制地址的兜底。

## 打包内置组件（v1.3.0）

- **包体积为什么变大、又为什么变小**：v1.2.0 单文件便携版 90MB；v1.3.0 把 VLC zip（75MB）与 Chromium zip（209MB，已去掉 390MB 的测试程序，见 `bundled/README.md`）一起打进安装包，单文件便携版 371MB（实测）。v1.6.0 把 Chromium zip（209MB）移出安装包，单文件便携版 164.2MB（实测）；`dist/win-unpacked/resources/bundled/` 里只有 VLC zip（75MB）与 licenses，Chromium zip 已不在安装包里。
- **来源与许可证**：VLC 3.0.21（VideoLAN 官方，GPLv2）、Chromium 快照 160.0.8184.0（Chromium 官方快照服务，BSD 风格许可证；**不是 Google Chrome 稳定版**，快照是持续构建，没有自动更新）。许可证原文在 `bundled/licenses/`，详见 `THIRD-PARTY-LICENSES.md`。
- **更新方式**：组件不单独下载、也不单独更新，只随工具箱版本一起更新。换版本时打包者按 `bundled/README.md` 重新取官方原包、更新哈希。
- **首次运行**：启动时自动校验 sha256 并解压内置 VLC 到 `%APPDATA%\muse-desktop-toolbox\tools\`，之后直接认到。VLC 缺失或损坏时，播放器页会出现「重新下载（后备）」；Chromium 是首次使用浏览器时再下载（自检页与浏览器页都有下载按钮），没下载前点浏览器会明确提示去下载。
- **定制**：不从源码重编。已做的只有启动参数与预置配置：Chromium 启动带 `--lang=zh-CN`、首次启动写最小 Preferences（主页、语言、不弹默认浏览器提示）；VLC 只对内置版用工具箱自己的 vlcrc（网络缓存 2000ms）与 `--no-qt-privacy-ask`。能定制什么、没做什么，见 `CUSTOMIZATION.md`，不虚构。
