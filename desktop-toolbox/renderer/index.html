工具管理

真实可用
当前系统没有 winget（工具管理只在 Windows 上可用）。

搜索 winget 软件源和微软商店（未安装的也能搜到），搜到的直接点「安装」。只搜「工具来源」里启用的来源。

输入关键词搜索 winget 软件源。
点「刷新列表」读取这台电脑已装的软件。

软件包清单

把这台电脑装的软件导成一份清单文件；换电脑或重装后导入清单，一次把软件批量装回来（底层是 winget export / import）。

更新是真的更新：点「更新」后会跑 winget upgrade，更新完自动刷新已安装清单，并显示更新前后的真实版本号。

点「检查更新」看哪些软件有新版本。

登录 GitHub 后搜仓库、看 Releases；Release 里有 exe / msi 安装包的可以直接装，装完后在「已安装」里刷新核对。

GitHub 登录

未登录：需要个人访问令牌（Personal Access Token）才能搜仓库。

令牌存在本机配置里（%APPDATA%\muse-desktop-toolbox\config.json），只用来调 GitHub API；搜公开仓库用 classic 令牌不勾任何权限也能搜。

先登录，再搜索仓库。

Releases

在仓库行点「查看 Releases」。

点「检查必备环境」查看这台电脑缺什么。

空间

        

        
空间调用（电脑端）

        

          

            

              
空间调用开关

              
空间使用工具箱默认的浏览器/播放器。打开后，电脑上的空间点播放 / 打开链接时，会通过 muse-toolbox:// 协议交给本程序的默认播放器 / 默认浏览器；关掉后协议调用会被拒绝，空间会走它自己的兜底。

            

            
          

          

            
            
          

          
协议地址（空间就是按这两个调的）：

          播放：muse-toolbox://play?url=<视频地址> → 默认播放器

          打开链接：muse-toolbox://browse?url=<网页地址> → 默认浏览器

          打开工具箱：muse-toolbox://home

        


        
备份与同步

        
一键导出全部本地数据（智能体、聊天记录、记账本、注册记录、设置等）成一个备份文件；导入前会自动把当前数据先备份一份。同步文件夹是手动同步、不是自动互通：指定一个文件夹，点「同步到文件夹」写一份备份进去，另一台电脑从同一文件夹读回。

        

          

            

              
数据备份（.toolboxbak）

              
默认不含密钥（智能体密钥、GitHub 令牌、图片接口密钥会剔除）；勾选「包含密钥」才带上。密码保护用 AES-256-GCM 加密，忘密码就打不开。

            

          

          

            
            
            
            
          

          

        

        

          

            

              
同步文件夹（手动同步）

              
未指定同步文件夹（可用 U 盘、网盘同步目录或局域网共享文件夹）。

            

            
          

          

            
            
          

          
先选同步文件夹。
