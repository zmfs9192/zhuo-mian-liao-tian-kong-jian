## 3. 本轮修掉的真 bug（按实测）

1. **`--color-foreground: var(--text)` 在深色下失效（真 bug，自测 run 1 抓到）**：自定义属性的 var() 在 :root 上解析时就定死成浅色值并继承下去，深色块改 --text 也影响不到它——深色下 select 的 option 文字是 #171717 配 #18181b 底，对比度约 1.3:1，基本看不见（旧代码是三条规则各写死值，没这个问题，是本轮令牌化引入的回归）。修法：--color-foreground 两主题各写死值（#171717 / #f5f5f7），注释里写清原因；自测 `darkOptionColors` 回归通过，`designTokens` 加 3 叶钉住（两主题值 + 禁 var(--text) 别名）。同类检查：--color-ring 引用的 --accent 两主题相同，安全；--text/--text-secondary/--bg-muted 都在深色块里重定义过，安全；--input-bg 深色直接写 rgba，不走别名，安全。
2. **容器查询量内容盒、断点按外宽写会误判（真坑，沙盒实测抓到）**：侧栏 240px 外宽、16px 内边距时内容盒 208px，按旧思路写的 220 断点会把它判进纯图标档。修法：断点按内容盒写（187/267/347），注释写死换算；自测 240px 下 3 列图标+文字通过。
3. 自测自身问题 2 个（非产品回归）：`computedPrimary` 断言把自定义属性的计算值当成 rgb（实际返回原值 `#171717`）；`rowPadding` 探针从已移除节点的 live `getComputedStyle` 读值（改成移除前先取值）。
